第71回：繰り返しタスク＋複数ページ連動

【先に確認】
1. 第70回の「クラウドをバックアップ」でJSONを保存してください。
2. Supabase管理画面のSQL Editorで schema.sql を一度だけ実行してください。
   既存のtasksのデータは消しませんが、テーブルの列と索引を追加します。
3. Supabaseの public.tasks に本人限定のRLSが設定されていることを確認してください。
   この教材のschema.sqlはtasksの既存ポリシーを変更しません。
4. ZIPを展開し、index.html, recurring.html, css/, js/ を
   GitHub Pagesの公開リポジトリの同じ階層にアップロードしてください。
5. index.html から「繰り返し設定」を開いてルールを登録します。
6. 「タスク一覧」に戻ると、ルールに基づいてタスクが生成されます。

【仕様】
・曜日（複数選択）、毎月第○曜日（第1～5、最終を複数選択）、毎月日付、毎年月日
・予定日の0～30日前にタスクを生成
・開始日以降の予定を生成。開始日が5年以上前なら安全のためエラーを表示
・過去の未完了タスクは残し、次回分を別タスクとして追加
・DBのUNIQUE制約で同じルール・同じ予定日の二重登録を防止
・繰り返し設定を停止しても、既存のタスクは残る
・月末に存在しない日（例：2月31日）と、平年の2月29日は発生しない
・自動生成は「タスク一覧」を開いたとき／再読み込み時のみ
・アプリを開かなくても毎日生成するサーバー側の定期実行は未実装
・完了から7日経過したタスクの削除は第70回の設定を継承（バックアップ後の有効化）

【注意】
・新規の繰り返しタスクは自動生成されます。開始日を過去にすると、その分も生成されます。
・ルールの編集は過去に生成済みのタスクを変更しません。
・ルールを停止すると将来分の新規生成を止めますが、既存タスクは残ります。
・設定テーブルにデータがない場合も画面は正常に開きます。
・GitHub Pagesで公開する前にSQLとRLSの設定を確認してください。
